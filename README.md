# Pineapple Animation

A small, fun CSS & JavaScript animation that draws and animates a pineapple using HTML, CSS, and a little JavaScript.

![Pineapple Animation Screenshot](./Screenshot%202024-08-30%20101447.png)

## Overview

This repository contains a single-page animation built with semantic HTML, modern CSS (including keyframe animations), and a tiny bit of JavaScript to enhance behavior. The project is lightweight and easy to run locally — no build tools or package managers required.

## Features

- Pure CSS-driven visuals and animation
- Responsive layout that works in modern browsers
- Small, easy-to-read codebase (mostly CSS)

## Demo

Open `index.html` in your browser to see the animation. You can also preview the screenshot above for a quick look.

## How to run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/BinaryVortex/Pineapple-Animation.git
   cd Pineapple-Animation
   ```

2. Open `index.html` in your browser (double-click or run):

   ```bash
   # macOS / Linux
   xdg-open index.html

   # macOS (alternative)
   open index.html

   # Windows (PowerShell)
   Start-Process index.html
   ```

No additional dependencies required.
